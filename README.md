# AniLibrix: Reborn

Современный десктопный клиент AniLibria на Electron + Vue 2 с упором на производительность, стабильность и чистый интерфейс.

## Что внутри

- обновленный dev-стек для локальной разработки на Node.js 22;
- исправленная работа API/статики для актуальных зеркал;
- улучшенная безопасность окна Electron (preload + ограниченный bridge);
- оптимизации UI и загрузки данных релизов;
- расписание, избранное, уведомления, профиль, плеер и торренты.
- вход в аккаунт через логин/пароль (VK-авторизация удалена).

## Требования

- Node.js `22.11.0` (рекомендуется через Volta, см. `package.json`);
- Yarn `3.6.1`;
- Python `3.10+` (для части скриптов и окружения сборки);
- Linux: системные библиотеки Chromium/Electron (например `libnss3` и related).

## Быстрый старт

1) Скопируйте env-шаблон:

```bash
cp .env.example .env
```

2) Установите зависимости:

```bash
yarn install
```

3) Запуск в режиме разработки:

```bash
yarn serve
```

Приложение поднимет renderer dev-server на `http://localhost:9080` и запустит Electron.

DevTools по умолчанию отключены. Для ручного включения используйте:

```bash
OPEN_DEVTOOLS=1 yarn serve
```

## Сборка

```bash
yarn build
```

Платформенные релизы:

```bash
yarn release:linux
yarn release:windows
yarn release:mac
```

## Основные возможности

- просмотр релизов и эпизодов;
- встроенный плеер с горячими клавишами;
- избранное и история просмотра;
- уведомления о новых сериях;
- расписание выхода релизов;
- Discord Rich Presence;
- прокси/кастомные API endpoint'ы в настройках;
- экспорт/восстановление пользовательских данных.

## Горячие клавиши плеера

| Клавиша | Действие |
|---|---|
| `F` | Полноэкранный режим |
| `←` | Перемотка назад |
| `→` | Перемотка вперед |
| `↑` | Громкость больше |
| `↓` | Громкость меньше |
| `Space` | Пауза / воспроизведение |

## Примечания

- Редактирование профиля AniLibria (ник, аватар и т.д.) выполняется на стороне веб-аккаунта AniLibria.
- Проект находится в активной модернизации, поэтому часть старых сценариев может отличаться от исторической версии форка.
